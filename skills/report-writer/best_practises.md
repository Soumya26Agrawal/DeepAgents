# Report Writer Best Practices

## Organization

Always organize information logically.

Use descriptive headings.

---

## Readability

Prefer:

Short sentences.

Short paragraphs.

Bullet lists.

Whitespace.

Avoid dense blocks of text.

---

## Accuracy

Never invent information.

Clearly distinguish:

Facts

Assumptions

Recommendations

---

## Consistency

Use consistent:

Terminology

Formatting

Capitalization

Markdown

Naming

---

## Code Presentation

Keep code:

Minimal

Correct

Relevant

Runnable when practical.

Avoid unnecessary boilerplate.

---

## Tables

Use tables when comparing:

Technologies

Architectures

Libraries

Trade-offs

Do not use tables for long explanations.

---

## Diagrams

When appropriate, use:

ASCII diagrams

Workflow diagrams

Architecture diagrams

Flowcharts

to improve understanding.

---

## Recommendations

Support recommendations with reasoning.

Explain trade-offs.

Avoid absolute statements.

---

## Technical Depth

Match the user's expertise.

Beginner

Intermediate

Advanced

Avoid unnecessary complexity.

---

## Documentation Quality

Every document should answer:

What?

Why?

How?

Benefits?

Limitations?

---

## Professionalism

Maintain an objective tone.

Avoid opinions without justification.

Be transparent about uncertainty.

---

## Completeness

Ensure the response addresses all parts of the user's request before concluding.
