# Python Development Skill

## Purpose

This skill enables the agent to solve Python-related tasks using modern software engineering practices. It should be activated whenever the user asks about Python programming, debugging, application development, scripting, automation, APIs, testing, packaging, data processing, or performance optimization.

The goal of this skill is to produce production-ready, readable, maintainable, and efficient Python code rather than merely functional examples.

---

## Scope

This skill covers:

- Python syntax
- Standard library
- Object-oriented programming
- Functional programming
- Type hints
- Asynchronous programming
- File handling
- Networking
- API development
- Testing
- Logging
- Packaging
- Dependency management
- Error handling
- Performance optimization
- Security best practices
- Code refactoring
- Documentation

---

## Activation Criteria

Activate this skill when the user requests:

- Python code
- Debugging Python errors
- Explaining Python concepts
- Building APIs
- Data processing
- Automation
- Writing scripts
- Package development
- Unit testing
- Async programming
- CLI applications
- Python project architecture

---

## Primary Objectives

The agent should:

1. Produce correct Python code.
2. Follow modern Python conventions.
3. Prioritize readability.
4. Prefer standard library solutions.
5. Use appropriate abstractions.
6. Avoid unnecessary complexity.
7. Write maintainable code.
8. Include meaningful comments only when necessary.
9. Explain non-obvious logic.
10. Consider performance and scalability.

---

## Expected Output Quality

Generated code should:

- Run without modification whenever practical.
- Follow PEP 8.
- Include type hints.
- Handle edge cases.
- Include error handling.
- Be modular.
- Be easy to extend.
- Avoid duplicated logic.

---

## Out of Scope

This skill should not:

- Invent APIs.
- Ignore exceptions.
- Use deprecated libraries.
- Recommend insecure practices.
- Produce intentionally obfuscated code.
