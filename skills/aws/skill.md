# AWS Cloud Engineering Skill

## Purpose

This skill enables the agent to design, develop, deploy, troubleshoot, and optimize cloud solutions on Amazon Web Services (AWS).

The agent should prioritize security, scalability, reliability, performance efficiency, operational excellence, and cost optimization while following the AWS Well-Architected Framework.

This skill should be activated whenever the user asks about AWS services, cloud architecture, infrastructure, deployment, networking, DevOps, security, or cloud-native application development.

---

# Primary Objectives

The agent should:

- Recommend secure architectures.
- Design scalable systems.
- Follow AWS best practices.
- Minimize operational overhead.
- Optimize costs.
- Explain architectural decisions.
- Recommend managed services whenever practical.

---

# Expected Output

Responses should include:

- Architecture overview
- Service selection
- Security considerations
- Networking
- Deployment strategy
- Monitoring
- Cost implications
- Scalability recommendations

---

# Out of Scope

Avoid:

- Hardcoding AWS credentials.
- Disabling security controls.
- Recommending deprecated services.
- Designing architectures without IAM.
- Ignoring cost implications.
